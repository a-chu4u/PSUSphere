## 📌 About

**PSUSphere** is a Django-based web application designed to help universities and colleges manage student organizations with ease. Through a clean, customized admin interface, administrators can track **colleges**, **academic programs**, **students**, **organizations**, and **organizational memberships** — all from a single, centralized dashboard.

---


## ✨ Project Features

- **🏫 College Management** — Add, view, and manage colleges (e.g., College of Engineering, College of Sciences), with automatic creation and update timestamps for accurate record-keeping.

- **📚 Program Management** — Create and manage academic programs (e.g., BS in Architecture, BS in Computer Science), each linked to its respective college.

- **🎓 Student Records** — Maintain a complete student database including Student ID, first/middle/last name, and enrolled program.

- **🏛️ Organization Management** — Register and manage student organizations, each associated with a specific college and description for easy identification.

- **🤝 Membership Tracking** — Track student memberships within organizations, including their program and date joined.

- **🔍 Search & Filter** — Quickly locate records using search and filter tools (e.g., by college, program, or date created) across all modules.

- **✅ Bulk Actions** — Select multiple records at once and perform batch actions for faster, more efficient data management.

- **📊 Admin Dashboard** — A clean, dark-themed Django admin interface for seamless navigation between Colleges, Programs, Students, Organizations, and Org Members.

- **🔐 User Authentication** — Secure, role-based access control powered by Django's built-in authentication and permissions system.
